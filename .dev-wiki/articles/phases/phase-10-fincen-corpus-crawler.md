# Phase 10: FinCEN corpus crawler (SCALE)

## Objective

Widen the authoring scraper from one hand-registered advisory to the **discovered FinCEN
advisory corpus**: replace the static 1-entry `REGISTRY` in `acquire_fincen.py` with a
**generated manifest** (`data/fincen/index.json`) produced by a new authoring-only
`crawl_fincen.py`. This is the original M6 vision's next increment, building on the proven
acquire→convert pipe.

## Approach

**"Crawl all" ≠ "download all."** The ship artifact does not change; the crawler builds
*corpus / provenance*. The high-value, testable, low-bloat core is **discovery** — a generated
manifest of the corpus — not mass-downloading hundreds of PDFs into the repo.

Split for determinism (the project's deterministic-validators-at-boundaries value): a live web
crawler is non-deterministic and cannot be a smoke/CI check, so —

- **`parse_index(html) -> [entries]`** — a PURE function (HTML → `{id, title, date, type, url}`),
  verified offline by `crawl_fincen.py --selftest` against a saved fixture page (same runnable
  stdlib-check ethos as Phase-9 `build.py --check`).
- **`fetch_index()`** — a thin live shell (stdlib `urllib`, browser UA + timeout, polite), a
  **manual authoring run** that refreshes the fixture; never in smoke/CI.

The committed `data/fincen/index.json` is generated by `parse_index(saved_fixture)`, so it is
**reproducible offline** without a live fetch. `acquire_fincen.py` reads the manifest (id→url),
merging the static EFE entry as a guaranteed fallback so `fin-2022-a002` never breaks. The
widened pipe is proven on a **bounded batch (~2–3 ids)**, not the whole corpus.

## Scope

Files affected:
- `scripts/crawl_fincen.py` — NEW authoring-only: pure `parse_index` + `--selftest` + thin `fetch_index` + manifest writer.
- `scripts/acquire_fincen.py` — load `REGISTRY` from the manifest (static EFE entry merged as fallback); `--list` shows the manifest.
- `data/fincen/index.json` — NEW committed manifest of the advisory corpus.
- `tests/fixtures/fincen-index.html` — NEW saved index page (deterministic parser fixture).
- `README.md`, `CLAUDE.md` — document the crawler + generated-manifest model.

## Exit Criteria

- [ ] `crawl_fincen.py --selftest` parses `tests/fixtures/fincen-index.html` → ≥3 well-formed `{id,title,date,url}` entries, exits 0; non-zero on malformed parse
- [ ] `data/fincen/index.json` committed, valid JSON array (≥3 entries incl. `fin-2022-a002`), reproducible offline from the fixture
- [ ] `acquire_fincen.py --list` lists the manifest (≥3 ids incl. `fin-2022-a002`); `acquire fin-2022-a002` still resolves to the canonical URL (backward-compatible)
- [ ] bounded batch (~2–3) acquired+converted as a recorded authoring run → sampled `data/fincen/<id>.md` non-empty
- [ ] crawler + manifest documented in `crawl_fincen.py`/`acquire_fincen.py` docstrings + README + CLAUDE
- [ ] `git diff index.html` empty; `data/fincen/raw/` still gitignored; no bulk-md commit

## Constraints (load-bearing)

- **Authoring-only, never in the ship file** — `crawl_fincen.py` is a developer tool; the engine never imports it, `build.py` stays stdlib, the ship artifact never fetches. Prevents leaking network into `file://`.
- **Stdlib-only crawler** — no `requests`/`bs4`; `urllib` + a hand parser. Prevents a new runtime/authoring dep creeping toward the build. (markitdown stays confined to `pdf_to_md.py` in the uv venv.)
- **Deterministic committed manifest** — `index.json` is produced by `parse_index(saved_fixture)`, not a live crawl. Prevents non-reproducible, network-dependent committed state.
- **Engine/ship untouched** — `git diff index.html` empty; the SCALE work is authoring-side only.
- **No repo bloat** — `data/fincen/raw/` stays gitignored (PDFs regenerable); commit the manifest + only the md actually derived from. Prevents committing hundreds of MB.
- **Backward-compatible acquire** — static EFE entry merged as fallback so `fin-2022-a002` always resolves.

## Checkpoints

- After T1 (probe): if FinCEN's index is JS-rendered / requires auth / blocks scraping such that no deterministic parser can be built from a saved page — STOP and report; pivot to a hand-curated manifest (still an upgrade over the 1-entry stub).
- If blocked >3 attempts on a task: ask the user — skip or abort.

## Assumptions

- FinCEN exposes a server-rendered advisories index with stable, scrapeable advisory links + dates. If false: hand-curate the manifest (T1 abort path).
- The bounded batch's PDFs convert cleanly via the existing `pdf_to_md.py`/markitdown path. If a sampled PDF mangles: note it, pick another batch id — the EFE de-risk gate already proved the converter on one advisory.
