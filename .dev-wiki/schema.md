# Dev Wiki Schema

## Project Identity

- **domain:** AML / financial-crime detection — stakeholder-facing vision prototype
- **name:** AML Signal Engine — Vision Demo (signal-watch)
- **description:** A presenter-driven, offline, browser-based vision prototype that dramatizes an AML signal/atom monitoring loop. Not a detection system — a scripted, compliance-clean demo for stakeholder buy-in.
